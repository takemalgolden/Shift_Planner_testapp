# シフト管理アプリ：Windows単体サーバー化手順（試作版）

## 目指す構成
- 管理者PC（Windows 10/11）：サーバー実行ファイルを起動し、SQLiteデータベースをローカル保存
- 従業員PC：ブラウザで管理者PCへアクセス。従業員PCへのPython／Flaskのインストールは不要
- 通常運用時：インターネット接続不要を想定。ただし社内ネットワーク・Windowsファイアウォール等の設定は必要
- ビルド時：このフォルダ内の `build_windows_exe.bat` がポータブルPythonをダウンロードしてEXEを作成するため、ビルドするWindows PCでは一度インターネット接続が必要

## EXEを作る
1. ZIPをWindows 10/11のPCに展開します。
2. `build_windows_exe.bat` を右クリックし、必要に応じて「管理者として実行」ではなく通常実行で開始します。
3. ビルド時だけインターネット接続が必要です。画面の案内に従って処理します。
4. 完了後、`dist\ShiftPlannerServer\ShiftPlannerServer.exe` が作成されます。
5. `dist\ShiftPlannerServer` フォルダ全体を管理者PCへコピーします。EXEだけを単独でコピーしないでください。
6. 管理者PCでEXEを起動します。Windowsファイアウォールの許可は、社内IT担当者のルールに従って設定してください。
7. 起動後、管理者PC自身のブラウザで `http://127.0.0.1:5050` を開き、動作を確認します。
8. 別PCからは `http://管理者PCのLAN内IPアドレス:5050` でアクセスします。IPアドレスは社内IT担当者に確認し、可能ならDHCP予約などで固定してください。

## 重要な注意
- このZIPは既存の試作版に、Windows EXE化のためのビルド手順を追加したものです。**完成版・本番利用承認済みのシステムではありません。**
- EXEはこの実行環境では生成していません。Windows 10/11上で `build_windows_exe.bat` を実行して作成します。
- この構成では「従業員PCにPythonやFlaskをインストールしない」ことを目指しています。サーバーEXEには実行に必要なPythonランタイム等が同梱されます。
- 初回ビルドにはインターネットが必要です。完成したフォルダを社内PCへ配布した後の通常利用は、外部サービスに接続しない構成を想定しています。
- 社内LANで公開する前に、社内IT担当者にポート5050、Windowsファイアウォール、端末管理ポリシー、ウイルス対策ソフトの扱いを確認してください。
- 業務データを入力する前に、認証・アクセス制御・バックアップ／復元・複数PC同期を実環境で検証してください。
- 現行の試作版は、最適化エンジン、時間帯別スキル切替、Excel取込などの要件を満たしていません。勤務表を本番業務に使う前に、これらの実装と受入テストが必要です。
- 初期アカウントやサンプルデータの扱いは `README.md` も確認し、本番配布前に初期パスワードを変更してください。

## ビルド修正版について
`build_windows_exe.bat` は、埋め込みPythonの `python312._pth` で `import site` を有効化してから pip をセットアップするよう修正しています。前回 `Successfully installed pip` の後に `No module named pip` が出た場合は、この修正版のZIPを展開し直して使用してください。
